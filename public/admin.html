Owner reference

Publish with confidence.

This page is a guide, not a sign-in panel. Administration happens in the private GitHub repository, where only collaborators you approve can change course content.

About restricted files: “Draft” and “scheduled” keep files off the deployed website, but a public source repository exposes every committed file. Use a private repository for unreleased sheets. GitHub Pages does not provide per-student login protection.

Post an announcement

Edit content/content.json, add an object under announcements, and set visibility to public. Commit to main; deployment runs automatically.

Upload a lab sheet

Upload the PDF into source-materials/. Add its exact filename to the lab’s file field, for example lab-01-introduction.pdf. The build publishes it as a download.

Control visibility

  • public: included in the next deployment.
  • draft: visible only in the repository.
  • scheduled: published after releaseAt when the scheduled deployment runs.

Update course details

The same content file controls section schedule, policies, instructor details, and the “last updated” date. No HTML editing is needed for routine updates.

Keep this URL unlinked from the student navigation if preferred. Security comes from GitHub repository permissions—not from hiding this page.
